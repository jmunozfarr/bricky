# Portfolio screenshot assets

Add current, project-owned screenshots here when preparing a portfolio publication. Suggested filenames:

- `overview.png` — local services, library, catalog, inventory, and readiness.
- `catalog-viewer.png` — searchable official part detail and 3D viewer.
- `model-readiness.png` — imported model, piece coverage, and BOM statuses.
- `missing-parts.png` — derived wishlist with exact inventory editing.

Capture the running application rather than committing mockups that could drift from implemented behavior. Avoid including private filenames or unrelated desktop content.
